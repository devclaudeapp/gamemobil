Salle de jeux

Des petits jeux pour le téléphone, à jouer quand tu veux.

Sur iPhone, une icône de l’écran d’accueil garde sa propre sauvegarde : une partie commencée dans Safari ne la suit pas. Pour la reprendre ici, dans Safari : Le Fournil → Réglages → Sauvegarde et transfert → copier le code, puis le charger au même endroit dans le jeu ouvert depuis cette icône.

Les jeux

Chaque partie est enregistrée dans ce navigateur, sur ce téléphone (sur iPhone, une icône de l’écran d’accueil a sa sauvegarde à elle).
Pour l’installer : Partager → « Sur l’écran d’accueil » sur iPhone, menu ⋮ → « Installer l’application » sur Android.
